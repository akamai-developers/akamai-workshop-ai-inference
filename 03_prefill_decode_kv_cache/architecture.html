Module 3  ·  Prefill once, then decode token by token
A request runs in two phases. Prefill reads the whole prompt in one parallel pass and fills the KV cache. Decode then generates one token at a time, appending its key and value to the cache at every step.

The KV cache trades GPU memory for not recomputing the past: store each token's keys and values once, then reuse them every step. Without it, every step would recompute the whole prefix.
